# Security Policy

FocusFlow is an offline mobile application with no account system and no
network-based authentication. The primary exposure surface is local data and
mobile signing keys.

## Reporting a vulnerability

If you discover a security issue, please contact the repository owner via GitHub
at `@ciel57142-wq`.

Do not send private keys, passwords, or other secrets. Provide a clear report of
the issue, reproduction steps, and any impacted files or components.
